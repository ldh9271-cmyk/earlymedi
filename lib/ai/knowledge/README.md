# AI 상담 지식 베이스 (lib/ai/knowledge)

`/api/ai/chat`(실시간 AI 상담)이 병원·상품 DB 근거 외에 **일반 의료 지식**을 답변에 쓰도록 하는 자료 폴더입니다.
질문마다 관련 청크를 골라 시스템 프롬프트의 `KNOWLEDGE` 블록에 넣습니다(임베딩 없이 용어 일치, `retrieve.ts`).

| 파일 | 역할 |
|---|---|
| `docs/*.md` | 원본 문서(사람이 편집). 현재 ① `medical-terms-guide.ko.md` 의료용어·급여/비급여·시술/수술 가이드, ② `kbeauty-terms-guide.ko.md` K뷰티 비의료 서비스 용어 가이드(퍼스널컬러·헤어·메이크업·네일·반영구·속눈썹/왁싱·에스테틱·두피·포토·K-pop·패키지) — 둘 다 2026-10-21 |
| `chunks.generated.ts` | `docs/*.md` 를 표 행·절 단위로 쪼갠 검색 데이터 + 외국어 별칭 사전. **자동 생성, 커밋 대상** |
| `retrieve.ts` | `retrieveKnowledge(question, { cats })` → 프롬프트용 텍스트. `KB_RULES` = 항상 넣는 상담 원칙(15장 요약) |

## 문서 추가·수정

1. Word 파일이면 변환: `node scripts/kb-import-docx.mjs <파일.docx> <이름>` → `docs/<이름>.md`
   (마크다운을 직접 써도 됨. 제목 `# N. 장`, `## N.M 절`, 표는 마크다운 표 — 표의 첫 칸이 용어가 됨)
2. 재생성: `node scripts/kb-build.mjs` → `chunks.generated.ts`
3. 확인: 질문 몇 개로 어떤 청크가 잡히는지 보려면 `retrieveKnowledge()` 를 tsx 로 호출해 본다.
4. 커밋·푸시(배포에 포함).

## 장 제목 → 카테고리 매핑

장 제목의 단어로 청크의 `cat` 이 정해지고(`scripts/kb-build.mjs` `CHAPTER_RULES`), 질문의 과·업종(route.ts `HOSPITAL_CATS`·`LISTING_CATS`)과 같으면 가중치가 붙습니다.
의료: 피부과·성형외과·치과·안과·정형외과·척추/통증·내과/검진·산부인과·비뇨·이비인후과·한의·모발이식 / 비의료: 퍼스널컬러·헤어 살롱·반영구·메이크업·네일·속눈썹/왁싱·두피·에스테틱/스파·포토 스튜디오·K-pop·패키지.
특수: '목차'·'부록'·'화자/내용' 대화 표는 제외, '대조표' 는 별칭 사전으로만, '상담 원칙' 은 rules, '사용 안내/목적' 장은 표만 포함(문서 구성 표 제외).
새 문서의 장 제목이 위 단어와 다르면 `CHAPTER_RULES` 에 한 줄 추가하세요.

## 답변 규칙(프롬프트에 고정)

- 지식은 일반 설명용 — 특정 병원의 시술·가격·결과로 말하지 않음(병원·상품 사실은 DATA 만).
- 단기 방문 외국인은 급여/비급여와 무관하게 병원 견적 전액 자부담, 가격은 병원별·단위(샷/cc/유닛) 확인.
- 기간·횟수는 "일반적으로/개인차" 로, 보장·최상급 표현 금지, 진단·처방 금지, 응급 증상은 119.
