# 토스페이먼츠 가입 · 연동 체크리스트 (glowuptour.com)

작성일 2026-07-30. 예약 팝업(코드)은 이미 토스 연동이 준비돼 있고,
환경변수 2개만 넣으면 알리페이 QR 대신 토스 결제창이 열린다.

---

## 1. 가입 신청 전 준비 서류

토스페이먼츠 가맹 신청(https://www.tosspayments.com) 시 필요.
개인사업자/법인 여부에 따라 아래에서 해당분만.

### 공통
- [ ] **사업자등록증** 사본
- [ ] **정산 계좌 통장 사본** — 사업자 명의 계좌 (개인사업자는 대표자 명의 가능)
- [ ] **대표자 신분증** 사본 (주민등록증/운전면허증/여권)
- [ ] **통신판매업 신고증** — 온라인 판매 필수. 미신고 상태면 관할 구청
      또는 정부24에서 먼저 신고 (등록면허세 약 4만원대, 1~3일 소요)

### 법인인 경우 추가
- [ ] 법인 등기부등본 (발급 3개월 이내)
- [ ] 법인 인감증명서 (발급 3개월 이내)
- [ ] 주주명부 (지분 25% 이상 실소유자 확인용 — 요청 시)

### 업종 관련
- [ ] 업종은 **"여행 알선/예약 대행, 뷰티 서비스 예약"** 으로 명확히 기재.
      의료행위 판매가 아니라 투어·예약 대행임을 설명할 수 있어야 심사가
      매끄럽다 (의료광고 고지 페이지 /legal/medical-ad 가 이미 있어 유리).
- [ ] 여행업 등록증이 있다면 첨부 (관광사업 등록 — 있으면 가산점, 없어도
      심사 시 서비스 구조 설명으로 대체 가능한지 문의)

## 2. 사이트 심사 요건 — glowuptour.com 에서 보완할 것

PG 심사관이 사이트를 직접 확인한다. 현재 상태 기준:

- [x] 이용약관 페이지 (/legal/terms — 취소·환불 포함) — 있음
- [x] 개인정보처리방침 (/legal/privacy) — 있음
- [x] 상품 가격 KRW 표시 — 있음
- [ ] **푸터 사업자 정보** — 현재 푸터에 상호·대표자명·사업자등록번호·
      통신판매업신고번호·주소·연락처(전화/이메일)가 없다. **심사 필수
      항목이라 반드시 추가해야 한다.** 실제 등록 정보를 주면 바로 푸터에
      넣어줄 수 있다.
- [ ] **취소·환불 규정을 상품 페이지 근처에서 접근 가능하게** — 현재
      "확정 전 무료 취소 48h" 문구는 있으나, 확정 후 환불 기준(며칠 전
      취소 시 몇 % 등)을 약관에 구체적으로 명시할 것 (여행업 표준약관
      준용 권장)
- [ ] **고객센터 연락 수단 명시** — 전화번호 또는 최소한 이메일/카카오톡
      채널을 푸터·문의 페이지에 표기

## 3. 계약 시 확인할 것

- [ ] **해외카드 결제 사용 신청** — 국내카드와 별도 옵션이다. 신청서에
      해외발급 Visa/Master/JCB 허용을 명시적으로 요청할 것 (수수료 약
      4.5%, 원화 승인·원화 정산)
- [ ] 객단가 안내 — 1건 200~300만원대 고액 결제가 기본임을 미리 알릴 것
      (건당 한도/이상거래 탐지 기준 협의. 미리 말 안 하면 초기에 승인
      거절이 잦을 수 있다)
- [ ] 정산 주기 (통상 D+2 영업일) 및 보증보험 요구 여부
- [ ] 국내 간편결제(토스페이/카카오페이 등) 동시 신청 여부 — 한국 고객
      대상이면 같이 열어두는 게 좋다

## 4. 연동 활성화 절차 (계약 완료 후 — 코드는 준비 완료)

1. [토스페이먼츠 개발자센터](https://developers.tosspayments.com) →
   내 상점 → **API 키** 복사
   - 테스트 키(`test_ck_…` / `test_sk_…`)로 먼저 검증 가능 — 계약 전에도
     발급된다
2. Vercel 프로젝트 환경변수에 추가 후 재배포:
   - `NEXT_PUBLIC_TOSS_CLIENT_KEY` = 클라이언트 키
   - `TOSS_SECRET_KEY` = 시크릿 키
3. 개발자센터 → **웹훅** 등록:
   - URL: `https://www.glowuptour.com/api/payments/toss/webhook`
   - 이벤트: 결제 상태 변경 (PAYMENT_STATUS_CHANGED)
4. 테스트: 예약 팝업 → 결제하기 → 토스 결제창(테스트 카드) → 완료 후
   마이페이지 결제내역이 자동으로 **결제 완료(paid)** 로 바뀌는지 확인
5. 라이브 키로 교체 → 실카드 소액 결제 1건으로 최종 확인 후 취소

## 5. 동작 방식 요약 (참고)

- 키 없음(현재) → 기존 알리페이 QR + 수동 확인 흐름 유지
- 키 설정 시 → 결제하기 클릭 → 인보이스 발행(GU-번호가 토스 orderId) →
  토스 결제창 → 승인 성공 시 서버가 금액을 DB 기준으로 재검증 후 토스
  승인 API 호출 → 인보이스가 자동으로 paid 처리되고 마이페이지로 이동.
  취소/실패는 웹훅이 토스 API 재조회로 동기화.
- 이용자가 결제창을 닫으면 예약 정보 화면에 남고 같은 인보이스로 재시도
  가능. SDK 로드 실패 시 알리페이 QR로 폴백.
