### 급여 여부 표기 기준


| 표기 | 의미 | 설명 |
|---|---|---|
| 급여 | 건강보험 적용 | 국민건강보험 가입자는 본인부담금(보통 외래 30~60%, 입원 20%)만 부담. 단, 대부분 조건(진단·증상·연령·횟수)이 붙음 |
| 비급여 | 건강보험 미적용 | 병원이 가격을 자율 책정. 미용·예방·편의 목적이 대부분. 병원별 가격 차이가 크며 반드시 "병원 확인 필요"로 안내 |
| 선별급여 | 부분 급여 | 유효성은 있으나 비용효과가 불명확한 항목. 본인부담 50~90%. 예: 일부 MRI, 초음파, 신약 |
| 조건부 급여 | 조건 충족 시 급여 | 같은 시술이라도 치료 목적이면 급여, 미용 목적이면 비급여. 예: 눈꺼풀처짐(시야장애) 수술, 코 비중격 교정, 유방재건 |
| 전액본인부담 | 100/100 | 급여 항목이지만 기준 초과 시 전액 본인부담. 예: 급여 기준 횟수를 넘긴 물리치료 |

※ 외국인(국내 건강보험 미가입자)은 급여 항목이라도 보험 적용이 되지 않아 일반적으로 전액 본인부담(병원 "외국인 수가" 또는 비급여 수가)으로 청구됩니다. 따라서 AI 상담 시 "급여/비급여"는 한국 제도 설명용으로만 쓰고, 외국인 환자에게는 "병원 견적 기준 전액 자부담"임을 기본 전제로 안내해야 합니다. 단, 한국 체류 6개월 이상으로 지역가입자가 된 외국인, 직장가입자인 외국인은 내국인과 동일하게 급여 적용됩니다.
※ 급여 기준(연령, 횟수, 적응증)은 보건복지부 고시로 수시 변경됩니다. 본 문서는 2026년 기준 일반적인 내용이며, 확정 안내 전 반드시 해당 의료기관 또는 건강보험심사평가원(hira.or.kr) 비급여 진료비 정보를 확인하도록 설계해야 합니다.

# 1. 모든 진료과 공통 기초 용어


## 1.1 시술 vs 수술 vs 처치의 구분


| 용어 | 정의 | 상담 시 설명 예시 |
|---|---|---|
| 시술 (Procedure) | 피부 절개 없이 또는 최소 절개로 하는 치료. 레이저, 주사, 고주파, 초음파, 실 삽입 등. 대개 국소마취·무마취, 당일 귀가 | "다운타임(회복기간)이 짧고 당일 일상 복귀가 가능한 비수술적 치료입니다" |
| 수술 (Surgery/Operation) | 절개·봉합을 동반하는 외과적 치료. 수면·전신마취가 많고 회복 1~4주. 실밥 제거(5~14일), 붓기·멍 동반 | "절개가 있으므로 실밥 제거와 경과 관찰을 위해 최소 7~14일 체류가 필요합니다" |
| 처치 (Treatment) | 드레싱, 주사, 소독, 물리치료 등 단순 의료행위 | "수술 후 소독·드레싱은 처치에 해당하며 별도 비용이 발생할 수 있습니다" |
| 쁘띠 성형 | 보톡스·필러·실리프팅 등 비수술 미용시술의 통칭 (업계 용어, 의학용어 아님) | "간단 시술(쁘띠)은 당일 가능하지만 효과 지속기간이 수개월입니다" |
| 복합 시술 / 패키지 | 여러 시술을 한 번에 묶어 진행하는 병원 상품명 (예: 울써마지 = 울쎄라+써마지) | 병원마다 패키지 구성·명칭이 다르므로 포함 항목(샷수, 부위, 횟수)을 반드시 확인 |
| 샷(shot) / cc / 유닛(unit) | 울쎄라·써마지·슈링크는 "샷" 단위, 필러는 "cc(ml)", 보톡스는 "유닛(U)" 단위로 가격 책정 | 같은 시술명도 샷수·용량에 따라 가격이 2~3배 차이. 견적 비교 시 단위 통일 필수 |
| 다운타임 (Downtime) | 시술/수술 후 붓기·멍·딱지 등으로 사회생활이 어려운 회복 기간 | 여행 일정과 직결. 귀국 전 여유일수 산정의 핵심 변수 |
| 정품·정량 | 보톡스·필러·스킨부스터 등에서 식약처 허가 정품을 정해진 양만큼 쓴다는 표현 | 외국인 환자가 가장 많이 묻는 신뢰 포인트. 제조사·제품명(예: 엘러간 보톡스, 쥬비덤) 확인 안내 |


## 1.2 마취 종류


| 용어 | 설명 | 적용 예 |
|---|---|---|
| 국소마취 (Local) | 시술 부위에만 리도카인 등 주사·연고. 의식 유지 | 보톡스, 필러, 점 제거, 치과 치료, 쌍꺼풀 매몰법 |
| 수면마취 (Sedation) | 프로포폴·미다졸람 정맥주사로 얕은 수면. 자가호흡 유지. 비급여 항목인 경우 많음 | 위·대장 내시경, 코·눈 성형, 지방흡입(부분), 라식·라섹은 보통 점안마취 |
| 전신마취 (General) | 기관삽관 또는 후두마스크, 마취과 전문의 필요. 금식 8시간 | 양악, 안면윤곽, 가슴성형, 복부성형, 인공관절, 척추 수술 |
| 척추/경막외마취 | 하반신만 마취 | 하지 정형외과 수술, 제왕절개 |
| 부위(신경)차단 | 특정 신경 주위에 마취제 주입 | 어깨·무릎 수술, 통증치료 |
| 치과 마취 | 침윤마취·전달마취(아래턱), 소아는 웃음가스(N2O) | 발치, 임플란트, 신경치료 |


## 1.3 진료 흐름 · 입원 · 검사 관련 용어


| 용어 | 설명 | 상담 포인트 |
|---|---|---|
| 초진 / 재진 | 처음 방문 / 이후 방문. 초진료가 더 높음(급여 기준 약 1.5배) | 외국인은 초진 상담료(비급여)가 별도인 병원 있음 |
| 외래 / 입원 / 당일수술(Day Surgery) | 통원 치료 / 병실 입원 / 당일 입·퇴원 | 입원 시 상급병실료(1~2인실)는 비급여 |
| 상급종합병원 / 종합병원 / 병원 / 의원 | 병상·진료과 수에 따른 등급. "의원"은 소규모(대부분 미용 클리닉) | "OO의원"이라도 전문의가 집도하는지 확인. "전문의"와 "일반의" 구별 안내 |
| 전문의 (Specialist) | 인턴·레지던트 수련 후 전문의 시험 합격. 예: 피부과 전문의, 성형외과 전문의 | 간판에 "피부과" vs "피부·미용"의 차이 — 전자는 전문의, 후자는 일반의도 가능 |
| 진료의뢰서 / 소견서 / 진단서 | 타 병원 의뢰 / 의사 의견서 / 공식 진단 서류(영문 진단서 비급여 2~3만원) | 외국인 환자는 귀국 후 보험 청구용 영문 진단서·영수증 요청 많음 |
| CT / MRI / PET-CT / 초음파 / X-ray | 단층촬영 / 자기공명 / 양전자 / 음파 / 방사선. MRI·초음파는 급여 조건 엄격 | 검진 목적 MRI는 비급여 30~80만원 수준(병원별 상이) |
| 혈액검사 / 소변검사 / 조직검사(생검) | 기본 검사 / 조직 떼어 현미경 검사 | 수술 전 기본검사(혈액·심전도·흉부X선)는 거의 모든 수술에 필수 |
| 감염관리 / 항생제 / 소염제 / 진통제 | 수술 후 기본 처방 | 약 처방전은 약국(원외)에서 조제. 외국인은 약값도 전액 부담 |
| 재수술 / 보증(A/S) / 리터치(Retouch) | 결과 미흡 시 재시술. 병원별 보증 기간·조건 상이 | 보증 조건은 반드시 서면(계약서/동의서)으로 확인하도록 안내 |
| 동의서 (Informed Consent) | 수술 전 위험·부작용 설명 후 서명 | 통역 입회 또는 다국어 동의서 제공 여부 확인 |


# 2. 피부과 (Dermatology)

피부과는 외국인 미용 의료관광의 최대 수요 분야입니다. 질환 치료(급여)와 미용 시술(비급여)이 명확히 나뉩니다.

## 2.1 급여 vs 비급여 개요


| 구분 | 대표 품목 | 비고 |
|---|---|---|
| 급여 (치료 목적) | 아토피·건선·습진·두드러기 진료 및 처방, 백선(무좀) 치료, 사마귀(냉동치료 급여), 대상포진, 여드름 "염증성" 진료·처방, 지루성 피부염, 탈모 중 원형탈모(치료 목적 주사), 피부암·전암병변 제거, 화상 치료 | 여드름 압출·레이저는 비급여. 사마귀 냉동치료는 급여이나 티눈·굳은살 제거는 병원마다 다름 |
| 비급여 (미용 목적) | 보톡스, 필러, 리프팅(울쎄라·써마지·인모드·슈링크 등), 스킨부스터(리쥬란·쥬베룩 등), 색소 레이저(토닝), 여드름 흉터 레이저, 제모, 점·검버섯 제거(미용 목적), 지방분해주사, 미백·광채 관리, 두피 관리, 모발이식 | 가격 100% 병원 자율. 동일 명칭이라도 장비 세대·샷수·팁 종류에 따라 차이 |


## 2.2 리프팅·탄력 (고주파 · 초음파 · 레이저)


| 용어 (시술/수술명) | 구분 | 급여 여부 | 설명 · 언제 받나 (적응증) | AI 상담 포인트 |
|---|---|---|---|---|
| 울쎄라 (Ulthera / Ultherapy) | 시술 | 비급여 | 미국 머츠(Merz)의 HIFU(고강도 집속 초음파). 피부 깊은 SMAS층(4.5mm)까지 열 응고시켜 콜라겐 재생·리프팅. 처진 턱선, 이중턱, 눈썹 처짐, 팔자주름. 1회 시술 효과 1년~1년 반. 통증 다소 큼. 보통 300·400·600·800샷 단위 판매 | 정품 울쎄라는 장비에 "Ulthera" 로고·정품 인증 스티커 확인. 슈링크·리니어 등 국산 HIFU와 가격 3~5배 차이. 보통 30대 후반 이상 추천 |
| 써마지 (Thermage FLX) | 시술 | 비급여 | 솔타(Solta)의 단극성 고주파(RF). 진피층 전체에 열을 가해 탄력·잔주름 개선, 모공 축소. 눈가(아이팁), 얼굴(600·900샷), 바디팁. 통증 적고 효과 6개월~1년. 처짐보다 "탄력·잔주름"에 적합 | "울쎄라=처짐(리프팅), 써마지=탄력·피부결" 로 설명. 둘을 같이 하는 "울써마지" 패키지 보편적. FLX(4세대)인지 CPT(3세대)인지 확인 |
| 인모드 (InMode) | 시술 | 비급여 | 이스라엘 인모드사 고주파. FX(지방 감소, 이중턱·볼살) + Forma(탄력) 조합. 비교적 저렴, 다운타임 없음. 20~40대 얼굴 지방 많은 경우 | "얼굴 살 빼기·턱선 정리"에 가성비 옵션. 1회보다 3~5회 코스 |

# 3. 성형외과 (Plastic Surgery)

성형외과는 미용성형(비급여)과 재건성형(급여)으로 나뉩니다. 외국인 환자 상담 수요의 핵심이며, 체류 일정·회복 기간 안내가 가장 중요합니다.

## 3.1 급여 vs 비급여 개요


| 구분 | 대표 품목 | 비고 |
|---|---|---|
| 급여 (재건·기능) | 유방암 후 유방재건, 화상·외상 후 재건, 구순구개열(언청이), 안검하수(눈꺼풀처짐 — 시야장애 동반 시), 비중격만곡 교정(기능적 코막힘), 여성형 유방(병적), 피부암 절제 후 재건, 수부 외상, 반흔 구축, 소이증 | 같은 수술도 "기능 개선"이 입증되면 급여. 외국인은 어차피 전액부담이나 "의학적 필요"를 설명하는 데 유용 |
| 비급여 (미용) | 눈·코·윤곽·양악(미용 목적)·가슴·지방흡입·지방이식·복부성형·리프팅·보톡스/필러·남성 성형·동안성형·입술·이마·귀 성형 등 | 병원별 수가 차이 큼. 전문의 집도 여부, 마취과 전문의 상주 여부 확인 |

# 4. 치과 (Dentistry)

치과는 한국 건강보험 급여 범위가 비교적 넓고(스케일링·충치 기본치료·신경치료·65세 이상 임플란트/틀니), 미용 치과(교정·라미네이트·미백·임플란트 일반)는 비급여입니다. 외국인 의료관광에서 임플란트·라미네이트·투명교정 수요가 높습니다.

# 5. 안과 (Ophthalmology)

# 6. 정형외과 (Orthopedics)

관절·척추·근골격계 질환. 치료 목적이 대부분이라 급여 비중이 높으나, 도수치료·체외충격파·프롤로·PRP·줄기세포 등 "비수술 통증치료"는 비급여입니다. 외국인은 인공관절·관절경·척추 수술·줄기세포 치료 문의가 많습니다.

## 6.1 급여 vs 비급여 개요


| 구분 | 대표 품목 | 비고 |
|---|---|---|
| 급여 | 진료·X-ray, 골절 치료(수술·깁스), 인공관절 치환술(무릎·고관절·어깨), 관절경 수술(반월상연골·십자인대·회전근개), 척추 수술(디스크 제거·유합술·감압술), 물리치료(기본), 관절강 내 주사(스테로이드, 히알루론산 — 조건), 골다공증 약물, 신경차단술(일부), MRI(급여 조건: 외상·질환 의심 시) | 히알루론산 주사는 6개월에 1쿠르 등 횟수 제한 |
| 비급여 | 도수치료, 체외충격파(ESWT), 프롤로테라피(증식치료), PRP 주사, 줄기세포(카티스템·자가지방줄기세포 일부), 콜라겐 주사, 고가 보조기·깔창, 신경성형술(경막외 유착박리), 풍선확장술, 고주파 수핵감압술, 비급여 MRI(검진·단순 통증), 로봇 인공관절 추가비, 상급병실 | 같은 "주사치료"라도 성분에 따라 급여/비급여 갈림 |

효과 보장 금지: "100% 효과", "완치", "부작용 없음", "최고", "1위", "유일" 등 단정적 표현 사용 금지. → "개인차가 있으며 일반적으로 ~한 효과를 기대할 수 있습니다"
비교·비방 금지: 타 병원·타 제품 비하, 근거 없는 우열 비교 금지
전후 사진: 환자 동의 없는 전후 사진 제공 금지. 병원이 제공한 동의된 사진만, 과장·보정 없이
가격 안내: "병원 공시 비급여 가격"을 기준으로, "병원별·상담 후 확정" 전제. 할인·이벤트 유도는 의료법 환자유인 금지(제27조) 저촉 가능 → 외국인 환자 유치업 등록 범위 내에서만
외국인 환자 유치업 등록: 글로우업투어는 보건복지부 외국인환자 유치업체 등록 필요(등록번호 안내). 미등록 알선은 불법
진단·처방 금지: AI는 진단·처방을 하지 않음. "의사 진료 후 결정" 문구 필수. 응급 증상(가슴통증·호흡곤란·의식저하·심한 출혈)은 즉시 119 안내
개인정보: 여권·의료기록·사진은 동의 하에 수집, 목적 외 사용 금지(개인정보보호법·의료법 비밀누설 금지)

## 15.3 급여/비급여 질문 응대 템플릿

외국인 환자: "이 시술이 보험 되나요?"
→ "한국 국민건강보험은 한국 거주·가입자에게 적용되며, 단기 방문 외국인 환자는 보험 적용 없이 병원 견적 기준 전액 자부담입니다. 다만 치료 목적 수술은 귀국 후 본국 보험사 청구를 위해 영문 진단서·영수증·진료기록을 준비해 드릴 수 있습니다. 미용 목적 시술(보톡스·필러·리프팅·성형)은 대부분 국가에서 보험 대상이 아닙니다."

# 부록. AI 상담 대화 예시 (학습용)


| 화자 | 내용 |
|---|---|
| 환자(중국) | 我想做热玛吉和超声刀，哪个更适合我？我35岁，脸有点松。 |
| AI | 35세에 얼굴 탄력 저하가 시작된 단계라면 두 시술 모두 고려 가능합니다. 울쎄라(超声刀)는 깊은 층(SMAS)을 당겨 "처짐"에, 써마지(热玛吉)는 진피 탄력·잔주름에 효과적이라 함께 받는 분도 많습니다. 정확한 적합 여부는 의사의 피부 진단 후 결정됩니다. 샷수(예: 울쎄라 300/400샷)에 따라 가격이 달라지니, 원하시면 2~3개 병원의 공시 가격을 비교해 드릴까요? 단기 방문이시면 두 시술 모두 다운타임이 거의 없어 당일 귀가 가능합니다. |
| 환자(일본) | 二重の埋没法を受けたいのですが、何日間滞在すれば良いですか？ |
| AI | 매몰법은 절개가 없어 실밥 제거가 필요 없고, 수술 당일 귀가 가능합니다. 다만 수술 다음날 경과 확인을 위해 최소 2~3일 체류를 권장드리며, 붓기는 1주 정도 지속될 수 있습니다. 눈꺼풀이 두껍거나 처짐이 있으면 의사가 부분절개·절개법을 권할 수 있고, 그 경우 실밥 제거까지 5~7일이 필요합니다. 사진을 보내주시면 병원 사전 상담을 연결해 드리겠습니다. |
| 환자(영어) | Is a dental implant covered by insurance in Korea? How many visits? |
| AI | 한국 건강보험은 65세 이상 가입자에게만 임플란트 2개까지 적용되며, 단기 방문 외국인은 전액 자부담입니다. 일반적으로 임플란트는 ① 식립(1일) → ② 3~6개월 골유착 → ③ 보철 장착(1~2회 방문)의 과정이라 2회 방한이 필요합니다. 뼈가 충분하면 "즉시 식립·임시치아" 방식으로 1차 방문 시 임시 치아까지 가능한 병원도 있습니다. 뼈이식이 필요하면 비용·기간이 추가됩니다. 국산(오스템 등)과 수입(스트라우만 등) 임플란트 가격 차이도 안내해 드릴 수 있습니다. |
